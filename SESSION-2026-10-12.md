## Findings

### The pasted analysis
- **Right:** KT Brain is the stronger pick. Its "KT is a coverage problem, not a Q&A problem" framing is distinctive. Custody is a known idea (taint tracking) in a crowded lane. Custody is the safer build.
- **Wrong or overstated:**
  - "No direct competitor" for KT Brain is false. CodeScene has an [Off-Boarding Simulation](https://codescene.io/docs/guides/simulations/offboarding-simulator.html) that shows code at risk when a developer leaves. CodeScene can't explain *why* a decision was made.
  - "Fewer entries in Track 03" is a guess. Chat-with-docs will be crowded.
  - Width vs depth counts features, not how much the graph does the reasoning. Judges score the latter.
  - The rein-ai.com claim is wrong. The site is an IT-services company that also sells smart window shades. It has no agent-observability product.
  - The OWASP claim is unverified. The Agentic Top 10 exists (announced Dec 9, 2025), with ASI01 Goal Hijack, ASI06 Memory/Context Poisoning and ASI07 Inter-Agent Communication. The landing page doesn't mention taint tracking. The PDF was not read.
  - The AccuKnox claim is partly right. It runs at the kernel level (eBPF / KubeArmor): process, file and network controls. It is not path or data-flow tracing, so it isn't a direct competitor to Custody's gate. The homepage returned 403; the findings come from its docs and blog.

### Risks flagged for KT Brain
- The 20-question benchmark is circular (we write both the questions and the answers). Replace it with a backtest on a real OSS maintainer handover.
- "Nobody else knows this" depends on the KNOWS formula. Phrase it as "no recorded evidence anyone else knows this".
- The why-trace's session → commit → decision link runs on synthetic data for the seed. Label it honestly.
- Day 2 is overloaded. Drop synthetic Slack/Jira first if time is short.
- GRAPH.COPY is only justified for multi-step what-ifs, not for removing one person.
- Script a Rule 3 demo moment: "RAG can't answer what only Arjun knows".
